抽油机井工况诊断：形态特征与近邻分类

独立打开 demo/index.html；在原门户点击“添加案例”，选择本文件夹，校验后添加。
场景 pr1；ID production-pump-knn。全部脚本本地运行，无网络依赖；外部链接仅为参考阅读。

数据：教学合成形态，绝非真实油田数据或完整物理仿真。
每条曲线82点，上下支各41点；位移统一采样。
正常支间距约为常量；供液不足用sigmoid形成局部收缩；阀漏使用sin(pi*x)圆滑包络。
所有类别有随机尺度、偏移、倾斜和扰动。生成代码在model.js中公开。
特征：归一化闭合面积（鞋带公式）、x在[0.1,0.35)、[0.35,0.65)、[0.65,0.9)的平均上下支间距。
距离：用训练集均值/标准差标准化后，计算欧氏距离；零标准差用1替代。
k近邻按票数分类，平票取类别顺序最前者；k最多取训练样本数。
基线：同一标准化空间中的最近类中心。
训练种子13001，每类60条，噪声0.035；测试种子290003，每类30条；交互种子700003，每次增加101。
测试噪声可变，训练集不重算。准确率、召回率和宏平均F1均实际计算。
近邻支持率不是校准概率；支持率低于0.8或最近距离大于2时显示教学复核提示，该规则未经矿场验证。

专业背景与算法参考见页面底部和case.json；本项目不复现所引论文的模型或成绩。
本包未包含学生个人信息；署名仅在最终报告与封面填写。

门户导入使用原站支持的 module 模式（Shadow DOM 样式隔离），内容自然撑高，不使用嵌套滚动框。demo/index.html 仍可独立打开；module.js 由工具从同一套演示源码生成。
